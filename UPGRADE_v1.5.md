# Upgrade Notes — v1.5

v1.5 adds the Enterprise Banking Suite on top of v1.4.

Major new areas: Corporate Banking, bulk payroll/supplier payments, Treasury, Trade Finance, Credit Risk, Collections, advanced fraud rules, sanctions/PEP demo screening, unified case management, GL v2, reconciliation, service desk, document/signature controls, API Gateway, webhooks/notification abstraction, PWA support, corporate portal, BI, backup/DR scheduling, monitoring, jobs, multi-currency, bilingual navigation, branding/receipts, consent, archives, immutable audit chain and high-risk configuration maker/checker.

For a clean evaluation, extract v1.5 into a new folder and allow it to create a fresh `data/crakbit-bank.sqlite` database. Do not copy an old database unless you specifically want migration testing.
